02 / HOW IT WORKS

Small operations.
Massively repeated.

Each PE holds a weight, multiplies an incoming feature and adds a partial sum. Repeated across 1,024 PEs, local communication forms the matrix engine.

CONCEPTUAL ILLUSTRATION
C = A × B

This 4×4 teaching view shows a wave of active MACs through a small array. Weights stay in the PEs; features move across rows and partial sums move down columns.

psumout = psumin + a × w

Illustrates data movement only. Scheduling and values do not reproduce cycle-accurate RTL behavior.

Macro-aware
hierarchical design.

Choose a tractable hardening boundary, verify it, and reuse it. The final core integrates 32 row macros directly with 80 SRAM macros.

SRAM placement sits near the consuming logic. Large grouped SRAM blocks forced long routing detours in the first floorplan.

Keep standard cells out of narrow gaps between row macros. Routing blockages separately control allowed metal layers.

06 / CONTRIBUTION 03

Physical agreement.
Functional disagreement.

A timing optimization swapped non-interchangeable inputs in a row macro. The resulting layout matched its netlist—and still computed the wrong answer.

DOCUMENTED CASE STUDY · PE 23

DRC and LVS answer different questions from functional verification.

PHYSICAL VERIFICATION

Final netlist→Layout→DRC / LVS

LVS matched the already-modified netlist. It could not establish equivalence with the original RTL.

FUNCTIONAL VERIFICATION

Reference RTL→Row comparison→Core GLS

Gate-level row models exposed column 23 mismatches, localized to PE 23, product bits 12–15.

THE ROOT CAUSE / AND2B_1

One inverted input.
Two different functions.

Checkpoint comparison isolated the failure after post-global-route repair_timing. The log reported one swapped instance: pins A_N and B.

Cell function verified against SkyWater’s functional Verilog. The input examples below are a Boolean teaching tool.

Inspect cell definition ↗
Reference
X = (~A_N) & B1
After swapping input signals
X′ = (~B) & A_N0

Mismatch: the inputs are not interchangeable.

  1. Localize

    Row netlist after CTS and step 15 matched; after timing-repair step 17 it failed.

  2. Prevent

    Add -skip_pin_swap to timing repair at every level. Rebuild the row macro.

  3. Regress

    2,000 random row cycles, zero mismatches. Rebuild core_v11 and run all three GLS matrix cases.

Reported evidence: pin-swap case and regression · row comparison script · Simulation-based comparison is not formal equivalence. No ASIC flow was rerun for this website.
